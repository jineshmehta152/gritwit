# GritWit Academy

> **Where thinking skills meet human values.**
> A premier, educator-led cognitive enrichment programme for children aged 6–9.

## Core Pillars & Skills
- **Critical Thinking**: Visual & spatial analogies, fact vs. opinion, cause & effect, perspective-taking.
- **Logical Reasoning**: Matrix patterns, coding & cipher rules, algorithmic loops, deductive syllogisms.
- **Comprehension**: Verbal analogies, contextual inferences, main idea distillation, emotional nuance.
- **Problem Solving**: Balance scales, Fermi logic, data sufficiency, spatial visualization & origami nets.
- **Character Corner**: Integrating empathy, intellectual courage, and perseverance into every session.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, Lucide Icons, Custom UI Components
- **TypeScript**: Strict Type Safety
- **Enrolment & Payments**: Online Razorpay Integration & Direct Admissions Booking
